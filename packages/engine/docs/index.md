# svertik engine docs

Non-destructive SVG effects and motion: a scene in JSON, an effect stack per object, keyframes and
interactions, evaluated to plain SVG.

- **[Guide for agents and developers](../AGENTS.md)**: how to use the engine, the scene format, animation,
  interactions and the conventions that matter.
- **[Reference](reference/index.md)**: every effect and primitive, with its parameters, defaults and a JSON
  snippet. Generated from the engine's schemas on every release.

These docs ship inside the npm package (`docs/` and `AGENTS.md`), so they always match the installed version.
