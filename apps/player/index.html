svertik · reproductor

El mismo motor del editor, pero solo con lo que la escena necesita: los efectos de la escena se cargan cuando llegan (cada uno es un trozo aparte) y las fuentes y el importador de SVG, solo si hacen falta.

Cómo se incrusta

<svg id="logo" data-svertik="escena.json"></svg>
<script type="module" src="svertik-player.js"></script>

O con JavaScript, para controlarlo:

import { play } from './svertik-player.js';

const player = await play(escena, '#logo');
player.stop();
