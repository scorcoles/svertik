# svertik

**Alpha 0.0.27 — Non-destructive SVG design and motion.** Non-destructive SVG editor: an SVG (or a primitive, or text) and a stack of effects recalculated live by a JS engine. The original geometry is never touched. Animate it with a timeline and bring it to any website as-is: flat SVG, the project in JSON, or runtime code reproducing the effects and animation.

An experiment by [VERTIK](https://www.vertik.net).  
**For AI Agents & Headless Engine Use:** [AGENTS.md](AGENTS.md) · [Engine & Effects Guide](docs/ENGINE_AND_EFFECTS.md) · [Scene Recipes](docs/SCENE_RECIPES.md).

## Features

- **Effects** (88), in the editor's menus:
  - **Deform:** Transform, Rotate 3D, Spherize, Twist, Bend, Bones, Taper, Gather, Compress, Shear, Wave, Ripple, Noise, Roughen, Round Corners, Blob, Spikes, Melt, Cylinder, Perspective, Envelope, Path Wrap, Morph, Trim, and breaking or combining the shape: Crack, Radial Cut, Damage, Mosaic, Voronoi, Boolean, Metaball.
  - **Repeat:** Clone, Mirror, Fractal, Particles.
  - **Draw** (new marks and lines from the drawing): Halftone, Wave Lines, Vector Grain, Crosshatch, Dithering, Contour, Pixelate, Flow Field, Network, Weave, String Art, Spirograph, Connect, Trace.
  - **Effect** (per element): Step, Each (formulas per element, and per-copy shape values), Stagger, Range, Field, Oscillate, Wiggle, Pulse, Shake, Rigid Pieces.
  - **Motion:** Gravity, Physics, Rigid Body, Soft Body, Rope, Explosion, Follow Path, Look At.
  - **Style:** Color, Tint, Paint, Gradient, Image Fill, Feather, Mask, Opacity.
  - **Glitch:** Slices, Blocks, Scanlines, Streaks, RGB Split.
  - **Filters:** Shadow, Blur, Glow, Grain, Displace, Bevel, Thicken, Tone.
- **Utils:** compositions, Instance (live copy of another object, with its own placement and stacked effects), Mouse Instance (copies generated by the pointer in Play), Effector (applies its stack to other objects separately, with staggered delay), Connector (dynamic line between two objects following them, with arrows) and Tracer (motion trail of an object during animation).
- **Primitives** (rectangle, ellipse, polygon, star, line, spiral, pawn) and **Text** converted to vector outlines (one piece per letter).
- **Animation:** keyframes on any value, easing curves (including back, elastic, bounce), and letter entrance presets.
- **JSON projects:** save (⌘S, ⇧⌘S to save as) and reopen (⌘O or dragging the file). Imported SVGs go inside the file, or, with **Document → SVGs** off, stay next to it as separate files. Export to SVG and PNG. The "svertik" menu includes built-in demos.
- **Strictly SVG:** exports pure, standard SVG.

## Getting Started

```bash
pnpm install
pnpm editor     # launches the web editor
pnpm player     # the player (the demo page of the embeddable bundle)
pnpm test       # runs tests (engine, UI, and editor)
pnpm typecheck
pnpm storybook  # UI components
pnpm size       # what the player weighs, and what a given scene weighs
```

`pnpm run deploy` publishes the hosted editor at https://editor.svertik.com/ from a clean, pushed `main`: it runs the tests, calls the private hosting step (outside this repository, set with `SVERTIK_HOSTED_DEPLOY`) and checks that the live editor reports the new version. `pnpm run deploy --dry-run` stops after the tests. GitHub Actions only run the tests; nothing is published from GitHub.

## Terminal CLI

```bash
pnpm svertik render project.json -o poster.png --scale 3 --background '#0d0d10'
pnpm svertik render project.json --frames frames/   # full animation as PNG frames
pnpm svertik info project.json
pnpm svertik effects --json                         # lists effects and parameters
```

## The Engine on the Web

```ts
import { builtins, createEngine } from '@svertik/engine';

const engine = createEngine(builtins);
const scene = {
  version: 1,
  objects: [
    {
      kind: 'object',
      id: 'logo',
      name: 'logo',
      source: '<svg viewBox="0 0 100 100"><rect x="10" y="10" width="80" height="80"/></svg>',
      stack: [
        { id: 'a', type: 'spherize', params: { strength: 0.6 } },
        { id: 'b', type: 'wave', params: { phase: 0 } },
      ],
    },
  ],
};

engine.toSVG(scene);                     // Flat standalone SVG
const live = engine.mount(svgEl, scene); // Mounted live into an <svg>
scene.objects[0].stack[1].params.phase = 90;
live.update(scene);                      // Efficiently recomputed only downstream from "wave"
```

The editor generates this code (including animations) in its **Code** panel.

## The player (to embed in a website)

The same engine, but only what the scene uses: its effects are loaded on demand (each one its own chunk),
and the fonts and the SVG importer only if the scene needs them.

```ts
import { createEngine, createPlayer, prepareScene } from '@svertik/engine/player';

const effects = await prepareScene(scene);          // loads only the scene's effects
const player = createPlayer(createEngine(effects), svgEl, scene);
```

`apps/player` builds it as a ready-made bundle (`svertik.js`) to drop in a page:

```html
<svg id="logo" data-svertik="scene.json"></svg>
<script type="module" src="svertik.js"></script>
```

The core is ~64 KB gzipped (shapes, animation, filters); each effect the scene uses adds its own chunk (`pnpm size` measures it).
